# WireGuard в Docker

Скрипт устанавливает и обслуживает WireGuard в Docker на Ubuntu 24.04.

## Установка

### Одной командой

Выполни на сервере Ubuntu 24.04 с установленным `curl`. Скрипт сохранит себя в `/usr/local/sbin/wireguard.sh`, установит WireGuard и откроет меню.

```bash
f=$(mktemp) && curl -fsSL https://raw.githubusercontent.com/thekhabaroff/wireguard/master/wireguard.sh -o "$f" && sudo bash "$f" && rm "$f"
```

При первом запуске скрипт проверит Ubuntu 24.04, установит Docker Engine и Compose при необходимости, затем попросит адрес сервера, UDP-порт и имена клиентских профилей. После запуска он покажет QR-код первого профиля.

## Управление

После первого запуска скрипт создаст команду `sudo wg` для открытия меню. Вызовы `wg` с аргументами передаются системной утилите WireGuard, если она установлена. Из меню можно добавлять устройства, отзывать профили, показывать QR-коды, смотреть состояние WireGuard, обновлять Docker-образ и удалять установку. Если `/usr/local/bin/wg` уже занят другой программой, скрипт не заменит её; используй `sudo /usr/local/sbin/wireguard.sh`.

Данные сервера находятся в `/opt/wireguard`: Compose-файл — `compose.yaml`, список профилей — `.env`, ключи и конфигурации клиентов — `config/`. Берегите QR-коды и файлы `.conf`: они дают доступ к VPN.

Откройте выбранный UDP-порт в firewall-панели VPS. Опубликованные Docker-порты могут обходить обычные правила UFW; подробности — в [документации Docker](https://docs.docker.com/engine/network/packet-filtering-firewalls/).

## Удаление

Пункт полного удаления просит ввести `WIPE`, затем удаляет контейнер, образ WireGuard, Compose-сеть и `/opt/wireguard` с ключами. Docker Engine, команда `wg` и файл скрипта вне `/opt/wireguard` остаются. Перед удалением сохраните зашифрованную резервную копию `/opt/wireguard`, если она нужна для восстановления.

Базовая конфигурация направляет через VPN IPv4-трафик. IPv6-маршрутизация отдельно не настроена. Скрипт использует образ `lscr.io/linuxserver/wireguard:latest`.
